# Prometheus + Grafana Monitoring on Minikube
This project demonstrates a complete monitoring system using Prometheus and Grafana on a Minikube Kubernetes cluster. It helps in monitoring Kubernetes cluster metrics such as CPU usage, memory consumption, and pod performance. The project integrates Prometheus as a monitoring tool and Grafana for visualization of real-time metrics
- Kubernetes (Minikube)
- Prometheus
- Grafana
- kubectl
- Docker

- - Deploy Minikube cluster locally
- Install Prometheus for metrics collection
- Install Grafana for visualization
- Monitor Kubernetes cluster resources
- Build real-time dashboards
